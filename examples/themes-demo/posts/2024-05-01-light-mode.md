# 暗色模式不是简单反转

纯黑底 + 纯白字，对比度 21:1。这不是暗色模式，这是闪光弹。

## 三件事

1. 背景用带色相的深灰，不是 #000
2. 正文用 #d0d6e0 一类的灰白，不是 #fff
3. 代码高亮单独设计一套

## 对比度

| 场景 | 目标对比度 |
| :--- | ---: |
| 正文 | ≥ 7:1 |
| 次要文字 | ≥ 4.5:1 |
| 边框 | ≥ 3:1 |
