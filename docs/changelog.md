## 怎么读

CHANGELOG 遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)：

| 分区 | 含义 |
| --- | --- |
| **Added** | 新增功能 |
| **Fixed** | 修掉的真 Bug（每条都配了会变红的负向验证） |
| **Security** | 安全相关 |
| **Engineering Notes** | 值得铭刻的踩坑 —— 边界条件、异步陷阱、测试写错方向 |
| **已知限制** | 如实标注没做的事 |
| **不做的事** | 明确立场：哪些方向被婉拒，以及为什么 |
